# DECA-AI

Módulo de IA de DECA: lee un ECG de 12 derivaciones y flagea indicios de cardiomiopatía chagásica (screening, no diagnóstico).

- [ROADMAP.md](ROADMAP.md) — contexto del problema, datasets, alcance.
- [FASES.md](FASES.md) — bitácora de decisiones, fase por fase, con los números que las sustentan.
- [SETUP.md](SETUP.md) — instructivo para dejar una PC nueva corriendo el pipeline, de cero.
- [CLAUDE.md](CLAUDE.md) — guía para Claude Code sobre la estructura del repo.
